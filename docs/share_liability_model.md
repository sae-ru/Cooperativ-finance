# Паи, поручительство и ограниченная ответственность

Статус: обязательная доменная policy; численные лимиты утверждает пилот.

## Паевые контуры

| Контур | Назначение | Автоматическое взыскание |
|---|---|---|
| Основной | членство и базовое участие | Нет |
| Protected amount | минимально защищённая часть основного | Запрещено |
| Гарантийный | добровольно принятые ограниченные риски | После решения в пределах reservation |
| Ролевой | риск критической должности | После доказанной причинной связи |
| Инфраструктурный | общие расходы/активы | Только по утверждённому назначению |
| Солидарный | безвозмездная помощь | Не является обеспечением |

Контуры не взаимозаменяются скрыто.

## Доступность и экспозиция

```text
available(account) = balance - active_reservations - executed_not_settled
member_max_exposure = sum(active_reservation.max_loss)
```

Protected amount исключается до расчёта available для подверженного взысканию
контура. UI показывает текущую и потенциальную экспозицию до подписи.

## Reservation

Reservation содержит account, конкретный risk, amount, max_loss, start,
expiry, release condition, priority и policy version. Оно не увеличивается и
не продлевается задним числом. Новое согласие создаёт новую reservation/version.

Одно reservation не может обеспечивать два независимых риска. Aggregate risk
проверяется по участнику, household/organization и связанным лицам.

## Поручительство

Поручительство действительно только при наличии:

- именованного поручителя;
- конкретного subject и beneficiary;
- суммы/количества и max loss;
- срока;
- условий вызова;
- reservation гарантийного контура;
- раскрытия связанных лиц;
- явного согласия поручителя на canonical summary.

Поручительство не означает автоматическую вину поручителя. Оно определяет
договорный слой покрытия после установленного trigger.

## Ролевая ответственность

Role bond связан с role assignment, scope, периодом и max exposure. Взыскание
требует доказанной причинной связи между действием/бездействием роли и ущербом,
классификации нарушения и финального решения после appeal window.

Истечение роли не освобождает уже возникший case, но запрещает новую операцию.

## Классы причин

- force majeure;
- добросовестная ошибка;
- небрежность;
- грубая небрежность;
- умысел;
- сговор.

Класс влияет на доступные меры, но не определяется одной формулой.

## Очередь покрытия

Базовый порядок, подлежащий юридическому утверждению:

1. восстановление/возврат конкретного актива;
2. добровольное исправление нарушителем;
3. его reservation, связанная с этим риском;
4. применимое ограниченное поручительство;
5. ролевое обеспечение при доказанной role liability;
6. специально созданный взаимный резерв/страховой контур;
7. основная паевая часть только по отдельному законному решению без protected
   amount;
8. дополнительный взнос только по предусмотренной процедуре, не программой.

Каждый слой создаёт отдельную execution entry. Неиспользованный остаток
reservation освобождается событием.

## Liability assessment

Содержит facts, source events, physical evidence, causal graph, affected
amount, fault classification, conflicts of interest, proposed coverage,
protected amounts, approvers, appeal period и execution state.

До finalization допускается временный freeze только для предотвращения нового
ущерба. Freeze не является взысканием.

## Инварианты

- execution <= finalized loss <= max exposure;
- сумма execution layers не превышает loss;
- protected amount не включается;
- donation/solidarity balance не включается;
- один layer не исполняется дважды;
- решение не принимает единолично заинтересованное лицо;
- appeal outcome может отменить или компенсировать исполнение;
- выход участника не удаляет active reservation.
