# ADR-0011: MIT и независимая реализация

Статус: Accepted.

## Context

Проект должен распространяться под MIT и сохранять проверяемое происхождение кода.

## Decision

Код проекта распространяется под MIT. Прямые dependencies допускаются только
с совместимыми лицензиями. Реализация и tests пишутся самостоятельно по ТЗ и ADR.

## Consequences

Нужны SBOM, license scan и журнал происхождения добавленного кода.

## Validation

Release gate проверяет licenses и provenance добавленного кода.
